# AI Feature Inventory

This inventory lists the implemented AI, semantic retrieval, semantic refresh, evaluation, and assistant features in the app repository.

---

## Generative And Reasoning Features

| Feature                      | User goal                                                                  | Input context                                                                                                                                 | AI/retrieval method                                                          | Output/storage                                                                                                         | Limitations                                                                                            | Status      |
| ---------------------------- | -------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ | ----------- |
| Resume critique              | Get feedback on a saved resume.                                            | Resume name/content and user career context.                                                                                                  | Gemini text generation through `src/lib/ai/resume-critique.ts`.              | Saves Markdown-style feedback to `Resume.aiFeedback` and `Resume.aiFeedbackAt`; rendered with safe Markdown UI.        | Does not use embeddings, job matching, streaming, or chat.                                             | Implemented |
| Cover letter critique        | Get feedback on an existing cover letter draft.                            | Cover letter content, cover letter metadata, linked application, job posting, company, and user career context.                               | Gemini text generation through `src/lib/ai/cover-letter-critique.ts`.        | Saves feedback to `CoverLetter.aiFeedback` and `CoverLetter.aiFeedbackAt`; rendered with safe Markdown UI.             | Does not generate a new cover letter or use retrieval embeddings.                                      | Implemented |
| Cover letter generation      | Generate a first-draft cover letter for an application.                    | Application, job posting, company, user career context, and linked resume when available.                                                     | Gemini text generation through `src/lib/ai/cover-letter-generation.ts`.      | Creates a `CoverLetter` with `mode = GENERATED`, generated `content`, and the next version number for the application. | Creates a draft for review; does not browse URLs, stream output, or send applications.                 | Implemented |
| Job posting summary          | Summarize a saved job posting.                                             | Job posting fields and company fields already saved in the database.                                                                          | Gemini text generation through `src/lib/ai/job-posting-summary.ts`.          | Saves summary to `JobPosting.aiSummary` and `JobPosting.aiSummaryAt`; rendered with safe Markdown UI.                  | Does not fetch the posting URL, compare against a resume, or produce a match score.                    | Implemented |
| Resume/job match             | Analyze how well one saved resume matches one saved job posting.           | Selected resume, selected job posting, company context, and user career context.                                                              | Gemini structured generation through `src/lib/ai/resume-job-match.ts`.       | Saves `JobPosting.matchScore`, `matchScoreAt`, `matchAnalysis`, and `matchResumeId`.                                   | Stores one current match result on the job posting; no match history or multi-resume comparison model. | Implemented |
| Resume tailoring suggestions | Suggest what to emphasize or adjust for a selected resume and job posting. | Selected resume, job posting, company, user career context, and relevant saved match analysis when available.                                 | Gemini text generation through `src/lib/ai/resume-tailoring-suggestions.ts`. | Saves `JobPosting.tailoringSuggestions`, `tailoringSuggestionsAt`, and `tailoringResumeId`.                            | Advice-only; does not edit resume content, create a resume version, or generate a cover letter.        | Implemented |
| Interview prep generation    | Generate saved prep notes for an interview.                                | Interview, linked application, job posting, company, optional linked resume, user career context, and relevant match analysis when available. | Gemini text generation through `src/lib/ai/interview-prep.ts`.               | Saves generated notes to `Interview.prepNotes`; rendered with safe Markdown UI.                                        | Uses the same field as personal prep notes; no separate generated-notes field yet.                     | Implemented |

## Retrieval, Embedding, Refresh, And Evaluation Features

| Feature                         | User/developer goal                                                                    | Input context                                                                                                 | AI/retrieval method                                                                                                | Output/storage                                                                                                                                        | Limitations                                                                                                                   | Status      |
| ------------------------------- | -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | ----------- |
| AI Retrieval Infrastructure     | Store semantic representations for resumes and job postings.                           | Resume name/content; job posting fields plus company name, industry, and notes.                               | `gemini-embedding-001` embeddings generated through `src/lib/ai/embeddings.ts` and stored with pgvector.           | `Resume.embedding`, `Resume.embeddedAt`, `Resume.embeddingTextHash`, `JobPosting.embedding`, `JobPosting.embeddedAt`, `JobPosting.embeddingTextHash`. | Only resumes and job postings are embedded in v1; no vector indexes or background queue yet.                                  | Implemented |
| Semantic test data              | Provide controlled records for repeatable semantic retrieval checks.                   | Synthetic companies, job postings, resumes, and applications created by `scripts/seed-semantic-test-data.ts`. | Deterministic IDs and known strong/medium/decoy relationships.                                                     | Seeded database records for a selected local/development user.                                                                                        | Intended for a dedicated test user; demo records are disposable and not production data.                                      | Implemented |
| Semantic Similar Records UI     | Show records that are semantically close to the current record.                        | Current resume or job posting plus saved candidate embeddings owned by the same user.                         | pgvector cosine distance through `findSimilarJobPostingsToResume` and `findSimilarResumesToJobPosting`.            | Similar jobs on resume edit pages and similar resumes on job posting edit pages, with approximate similarity scores.                                  | Requires current semantic data; does not generate explanations or guarantee fit.                                              | Implemented |
| Hybrid Job Posting Search       | Search saved jobs by keyword or meaning.                                               | User query, saved job postings, company fields, work mode filter, and company filter.                         | Keyword mode uses normal database filters; semantic mode embeds the query and ranks stored job posting embeddings. | `/job-postings` list with explicit keyword/semantic modes and approximate similarity scores in semantic mode.                                         | Semantic mode returns closest results and disables normal pagination; no blended ranking yet.                                 | Implemented |
| Hybrid Resume Search            | Search saved resumes by keyword or meaning.                                            | User query and saved resume name/content.                                                                     | Keyword mode uses normal database filters; semantic mode embeds the query and ranks stored resume embeddings.      | `/resumes` list with explicit keyword/semantic modes and approximate similarity scores in semantic mode.                                              | No structured resume filters in v1; no blended ranking yet.                                                                   | Implemented |
| Semantic Refresh UX             | Refresh semantic data for a single edited resume or job posting.                       | Current signed-in user and selected resume/job posting.                                                       | Per-record Server Action calls `generateResumeEmbeddingForUser` or `generateJobPostingEmbeddingForUser`.           | Updates embedding vector, timestamp, and text hash when the formatted embedding text changed.                                                         | Avoids automatic embedding generation on every save; still manual per record. Backfill remains a dev/bulk maintenance script. | Implemented |
| AI/Retrieval Evaluation Harness | Produce repeatable evidence for retrieval behavior and a rubric for generated outputs. | Synthetic semantic dataset and expected retrieval cases.                                                      | Manual rubric for generated outputs plus semi-automated retrieval script in `scripts/evaluate-retrieval.ts`.       | Terminal output or `docs/evaluation-results/retrieval-evaluation-latest.md`.                                                                          | Does not use LLM-as-judge and does not automatically grade generated prose. Assistant evaluation is not formalized yet.       | Implemented |

## Contextual Assistant Features

| Feature                             | User/developer goal                                                              | Input context                                                                  | AI/retrieval method                                                       | Output/storage                                                                 | Limitations                                                                          | Status      |
| ----------------------------------- | -------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------- | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------ | ----------- |
| Read-only contextual assistant      | Answer questions about saved job-search data without modifying records.          | Authenticated base context, optional page context, and read-only tool results. | Gemini assistant flow with read-only context and final structured answer. | Assistant answer shown in assistant UI with referenced records when available. | No database-persisted chat threads; no write actions.                                | Implemented |
| Read-only assistant tools           | Let the assistant gather focused saved-record context.                           | Signed-in user scope and model-requested tool parameters.                      | Typed server-side read-only tools.                                        | Tool results become assistant context and trusted source candidates.           | Tools cannot create, update, delete, send, or schedule.                              | Implemented |
| Page-aware assistant context        | Let the assistant understand the current resume, job posting, or application.    | Lightweight page descriptor from route/page plus server-side record lookup.    | Server resolves current-page context with `id + userId`.                  | Current-page summary is included in assistant context.                         | Only selected important pages have page-aware context.                               | Implemented |
| Source registry / trusted citations | Prevent invented references and show relevant records used by assistant answers. | Records included in base context, page context, or tool results.               | Server-side source map filters model-returned citation keys.              | Referenced records shown in UI after filtering, dedupe, and capping.           | Record references are not academic citations; they show app records used as context. | Implemented |
| Global assistant shell              | Make the assistant available across authenticated pages.                         | Authenticated app shell and route-derived page context.                        | Persistent shell UI plus contextual assistant action.                     | Floating launcher/drawer with context label and quick prompts.                 | Shell is not a persistent chat product yet.                                          | Implemented |
| Safe Markdown rendering             | Render AI outputs readably while avoiding raw HTML risks.                        | Read-only AI-generated Markdown-like output.                                   | Reusable Markdown renderer with unsafe HTML/link safeguards.              | Applied to assistant answers and stored AI outputs.                            | User-editable textareas remain plain text.                                           | Implemented |

## Current AI Non-Goals

The current implementation intentionally does not include:

- write-capable assistant tools,
- persisted assistant chat threads,
- automatic application submission,
- external job URL scraping,
- Gmail or Calendar integrations,
- automatic resume rewriting,
- automatic embedding refresh queue,
- production-scale vector indexing,
- LLM-as-judge evaluation.
